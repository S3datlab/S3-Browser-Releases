# S3 Browser

## Türkçe

S3, Apple WebKit tabanlı yerel bir Mac tarayıcısıdır. Sekmeler, çalışma alanları, yerel Brain hafızası ve desteklenen videolarda izlemeye devam etme özelliklerini bir araya getirir. Ücretsiz beta sürümüdür; uygulamanın geliştiriciye ait kaynak kodu kapalıdır. Bu repo indirmeler, yayın notları ve hata bildirimleri içindir.

**Gereksinimler:** Apple silicon Mac (M serisi), macOS 15.4 veya üzeri. Yerel modeller ek disk alanı kullanabilir.

1. [Releases](https://github.com/S3datlab/S3-Browser-Releases/releases) sayfasından en yeni macOS arm64 DMG’yi indirin.
2. DMG’yi açın ve lisansı inceleyin. Kabul ederseniz **S3 Browser**’ı **Applications / Uygulamalar** klasörüne sürükleyin.
3. Uygulamalar’dan açın. Developer ID ile imzalanmış ve Apple tarafından notarize edilmiş yayında macOS, ilk açılışta internetten indirilen uygulamayı açmak istediğinizi sorabilir; **Aç** seçeneğini kullanın. İmza veya zararlı yazılım uyarısı varsa işlemi durdurup bildirin; güvenlik ayarlarını devre dışı bırakmayın.
4. [Kullanım Koşulları](EULA.md) ve [Gizlilik Politikası](PRIVACY.md) metinlerini inceleyip ilk açılışta kabul edin. Sihirbazdan dil, izleme takibi ve S3 Browser Engine tercihlerinizi ayarlayın.

Hataları [Issues](https://github.com/S3datlab/S3-Browser-Releases/issues) üzerinden bildirin: uygulama sürümü/build, macOS sürümü ve tekrarlama adımlarını ekleyin. **Parola, API anahtarı, doğrulama kodu, kart bilgisi veya kişisel/gizli veri paylaşmayın.** Güvenlik sorunları ve özel destek: sedat@s3dat.com. Üçüncü taraf bileşenlerin kendi lisansları vardır; uygulama menüsünden açık kaynak lisanslarına erişilebilir.

## English

S3 is a native Mac browser built on Apple WebKit. It brings together tabs, workspaces, local Brain memory and playback progress for supported videos. It is a free beta; the developer’s app source is closed. This repository hosts downloads, release notes and issue reports.

**Requirements:** Apple silicon Mac (M series), macOS 15.4 or later. Local models may need additional disk space.

1. Download the latest macOS arm64 DMG from [Releases](https://github.com/S3datlab/S3-Browser-Releases/releases).
2. Open the DMG and review the license. If you agree, drag **S3 Browser** into **Applications**.
3. Open it from Applications. For a Developer ID signed, Apple notarized release, macOS may ask whether to open an app downloaded from the internet on first launch; choose **Open**. Stop and report signature or malware warnings; do not disable security settings.
4. Review the [Terms of Use](EULA.md) and [Privacy Policy](PRIVACY.md) and accept them at first launch. Choose language, watch tracking and S3 Browser Engine preferences in the wizard.

Report bugs in [Issues](https://github.com/S3datlab/S3-Browser-Releases/issues), including app version/build, macOS version and reproduction steps. **Do not post secrets:** passwords, API keys, verification codes, card details or personal/confidential data. Security issues and private support: sedat@s3dat.com. Third-party components retain their own licenses; open-source notices are accessible from the app menu. The Turkish legal texts prevail.
